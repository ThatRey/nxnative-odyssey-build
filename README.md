# nxnative Odyssey build

Temporary public repository for building a Super Mario Odyssey IPA with
[nxnative](https://github.com/seedds/nxnative) on GitHub Actions.

Game files, `prod.keys` and the IPA are not stored here. The workflow receives
the game over a token-protected, temporary Cloudflare tunnel and returns the
IPA the same way. Only the workflow, its source files and its logs are public.
